DBlocker Extension - Hướng dẫn cài đặt nhanh

CHROME
1. Mở chrome://extensions
2. Bật Developer mode (Chế độ cho nhà phát triển)
3. Bấm Load unpacked (Tải tiện ích đã giải nén)
4. Chọn thư mục DBlocker (thư mục chứa manifest.json)
5. Ghim icon DBlocker lên thanh công cụ trình duyệt

EDGE
1. Mở edge://extensions
2. Bật Developer mode
3. Bấm Load unpacked
4. Chọn thư mục DBlocker

Cách dùng:
- Mở trang web -> bấm icon DBlocker -> gạt bật Protection.
- BLOCK: Xem các mục đã bị chặn trên trang, Tải 1 lần (Load once) hoặc Luôn cho phép (Always allow).
- ALLOW: Quản lý quy tắc cho phép toàn cục, bấm Chặn lại khi muốn thu hồi.
- SITES: Quản lý các trang được bảo vệ theo site key (tự động bao phủ khi trang đổi đuôi .xyz, .cc, .net...).
